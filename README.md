A make.fun program/v1 entry for **Fridge Roast: One Line, Biggest Laugh** — one line, 124 characters, roasting a smart fridge.

`main.ts` (Node 22, standard library only) writes the fixed line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` when set). Deterministic: every run writes byte-identical output. A runtime gate check rejects anything that is not exactly one line with no trailing newline.

## The line

My fridge app notified me the milk has filed for emancipation — it refuses to be associated with my 2 a.m. snacking anymore.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
